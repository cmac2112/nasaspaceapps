> **Award-Winning Project at the 2024 NASA Space Apps Challenge**

**Solar Eye** is an interactive, educational simulation that lets users visualize planetary orbits, Near-Earth Objects (NEOs), and orbital mechanics using real NASA/JPL data—all within your browser. Built by the Bethel College Software Club, this app translates complex astrophysical data into an accessible and visually captivating experience for learners, educators, and space enthusiasts.

## 🚀 Live Demo

👉 [Explore Solar Eye Now](https://cmac2112.github.io/nasaspaceapps/#/solareyes)

---

## 🏆 What Makes Solar Eye Stand Out?

- **Award Winner at NASA Space Apps 2024:** Recognized for innovation, accessibility, and science communication.
- **Real Data Driven:** Fetches and visualizes up-to-date information on planetary bodies, Near-Earth Objects, and orbital elements from trusted sources like NASA and JPL's Small-Body DataBase (SBDB).
- **Immersive 3D Visualization:** Utilizes Three.js and React Three Fiber for interactive, browser-based planetary system simulations.
- **Educational Focus:** Clear in-app explanations for Keplerian elements, orbital mechanics, and celestial dynamics.

---

## 🌍 Features

- **Solar System Simulation:** Explore orbits of planets, major moons, and dynamically-loaded NEOs.
- **Responsive UI:** User-friendly navigation with contextual info panels and dynamic data loading.
- **Learn by Doing:** See mathematical concepts (like mean anomaly & true anomaly) visualized in real time.
- **Accessible for Learners:** Includes detailed “Info” sections to demystify orbital mechanics.

---

## 🧑‍💻 Built With

- **React 18** — Modern UI framework.
- **Three.js & @react-three/fiber** — Advanced 3D rendering.
- **Vite** — Ultra-fast dev/build toolchain.
- **NASA/JPL Public Data APIs** — For live, accurate celestial data.
- **TypeScript & JavaScript** — Robust and scalable codebase.
- **dat.gui** — User controls & simulation tuning.

---

## 📂 App Structure

- `solarSystem/src/components/` — Modular React components (simulation, info, landing page, layout, etc).
- `solarSystem/src/assets/` — Static data (JPL/NEO JSON), images, and supporting assets.
- `solarSystem/package.json` — Controls dependencies (React, Three.js, dat.gui, etc).
